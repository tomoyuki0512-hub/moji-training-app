# なぞりがき（moji_tracing）

4さい向けの、もじの「なぞりがき」れんしゅうアプリ（Flutter / iOS）。
ひらがな・カタカナ・アルファベット（大文字・小文字）を 1 文字ずつ、
指やタッチペンでお手本をなぞって練習できます。

## できること

- **1 文字ずつ練習**: カテゴリ（ひらがな / カタカナ / ABC / abc）を選び、一覧から文字をタップ。
- **お手本をなぞる**: 薄く表示されたお手本の上を指でなぞって書く。
- **書き順アニメ**: 番号と動く点で書き順を見せる。**ワンタッチで ON/OFF** でき、「もういちど みる」で再生し直せる。
- **お手本の ON/OFF**: ワンタッチでお手本を消せる。
- **けす**: ワンタッチで自分のなぞり線だけを消せる。
- **ペンの色・太さ**: 6 色・3 段階の太さから選べる（端末に保存）。
- **はなまる演出**: 書けたら 💮 とスターでお祝い。「もういちど / つぎ / いちらん」へすぐ移動。
- **進捗の記録**: クリアした文字に花丸の印を付けて一覧に表示（端末内に保存）。
- **シンプル・フラットなデザイン**: やさしいパステル配色。

### 対応文字

| カテゴリ | 文字数 | 内容 |
|---|---|---|
| ひらがな | 108 | 基本46 ＋ だくてん・半だくてん25 ＋ 小書き4 ＋ 拗音33 |
| カタカナ | 108 | 同上 |
| アルファベット大文字 | 26 | A–Z |
| アルファベット小文字 | 26 | a–z |

## 開発

```sh
flutter pub get
flutter analyze
flutter test
```

iOS の未署名 IPA は GitHub Actions（`.github/workflows/build-ios.yml`, macOS ランナー）でビルドされます。

## 書き順データの作り方

書き順データは `assets/strokes/*.json` に同梱しています。再生成は:

```sh
python3 tool/gen_strokes.py            # tool/kanjivg_src/ の同梱SVGから生成
# もしくは KanjiVG のチェックアウトを指定:
python3 tool/gen_strokes.py /path/to/kanjivg/kanji
```

各エントリは `{char, label, key, category, viewBox, strokes:[svg path d, ...]}`。
かなは KanjiVG（109×109 の 1 画ずつの SVG センターライン）から、アルファベットは
手書き定義から生成します。アプリ側は `path_drawing` で `d` を `ui.Path` に変換し、
`PathMetric` でアニメーション表示します。
